# 📊 Telecom Customer Churn Analysis

Аналитический pet-проект, демонстрирующий навыки работы с данными, SQL, Python и Power BI.

## Цель проекта
Проанализировать отток клиентов телеком-оператора и выявить факторы, влияющие на churn.  
Сформировать бизнес-рекомендации для снижения оттока и повышения выручки.

---

## Используемый стек

**Python:**  
pandas, numpy, matplotlib, seaborn  

**SQL:**  
агрегации, сегментация клиентов, оконные функции  

**BI:**  
Power BI, DAX  

---

---

## Подготовка данных (Python)

В рамках проекта были выполнены:
- очистка данных и обработка пропусков
- приведение типов данных
- исследовательский анализ (EDA)
- поиск факторов оттока

Основная метрика:
**Churn Rate ≈ 26%**

---

## SQL-анализ

В SQL были рассчитаны:
- общий churn rate
- churn по контрактам и способам оплаты
- ARPU (средний доход на клиента)
- сегментация клиентов по доходу
- поиск риск-сегментов

---

## 📊 Power BI Dashboard

Создан интерактивный дашборд с ключевыми метриками:

**KPI:**
- Total Customers
- Churned Customers
- Churn Rate
- ARPU

**Аналитика:**
- Отток по типу контрактов
- Отток по интернет-услугам
- Отток по способу оплаты
- Распределение клиентов по стажу

Дашборд позволяет анализировать churn по сегментам с помощью фильтров.

---

## Основные выводы

1️) Клиенты с помесячным контрактом уходят значительно чаще  
2️) Основной отток происходит в первые месяцы использования  
3️) Уходящие клиенты платят больше среднего  
4) Высокий churn среди пользователей оптоволоконного интернета
